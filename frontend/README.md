# Office Cook Assistant Web

Адаптивная React-клиентская часть первой версии. Доступны рабочие маршруты:

- `/balances` — «Балансы»;
- `/cooks/new` — «Новая готовка»;
- `/cooks/:cookId` — редактирование готовки;
- `/cooks` — «Готовки» с фильтрами, пагинацией и групповым расчётом.

Экранов просмотра и импорта платежей нет. Типизированные camelCase-контракты и HTTP-клиент находятся в `src/api`; сервер остаётся источником истины для всех расчётов.

## Требования

- Node.js 20.19 или новее;
- npm 10 или новее.

## Запуск

```bash
npm ci
npm run dev
```

Vite слушает только `127.0.0.1:5173`. Клиент использует относительный адрес `/api/v1`, а dev-сервер проксирует все запросы `/api/*` в backend `http://127.0.0.1:8000`, сохраняя исходный путь. Для другого локального адреса backend можно создать `.env.local`:

```dotenv
DEV_API_PROXY_TARGET=http://127.0.0.1:9000
```

В production `/api` должен направляться к backend тем же reverse proxy, который раздаёт frontend. При необходимости публичный API base URL можно переопределить через `VITE_API_BASE_URL`. Служебный endpoint готовности находится по `/health`, вне `/api/v1`, и не обслуживается versioned API-клиентом.

## Проверки

```bash
npm run build
npm test
npx playwright install chromium # однократно
npm run test:e2e
```

Unit-набор включает интеграционную проверку dev-proxy на временном HTTP-сервере, без backend и базы данных. Playwright запускает один responsive smoke-сценарий в размерах `390x844` и `1366x768`.
